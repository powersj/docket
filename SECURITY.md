# Security

Docket runs Claude Code on code from pull requests, so a way to escape its
sandbox, leak the GitHub token, or post to GitHub without your say counts as a
security bug.

## Reporting a vulnerability

Report it privately through
[GitHub's private vulnerability reporting](https://github.com/powersj/docket/security/advisories/new),
not in a public issue. Include the steps to reproduce it and what an attacker
gains. You'll get a reply within a week.

## Supported versions

Only the latest commit on `master` gets fixes.
